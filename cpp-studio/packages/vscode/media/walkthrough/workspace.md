# Your learning workspace

C++ Studio keeps everything in one ordinary folder (by default `~/CppStudio`):

```text
CppStudio/
├── projects/          ← real C++ projects you build, lesson by lesson
│   ├── hello/
│   ├── calculator/
│   └── ...
└── .cpp-studio/       ← your progress, so you can stop and resume any time
```

The projects are yours: you can build them without C++ Studio, put them in Git, and keep extending them.
Updating C++ Studio never touches this folder.
