# Real tools, not a simulation

Every program you write in C++ Studio is compiled by the **real compiler** on your computer and run as a real program.

You need:

- **a C++ compiler** — g++, clang++ or Microsoft's MSVC
- **CMake** — the standard C++ build system (from the third lesson on)
- **a debugger** — gdb or lldb (from the debugger lesson on)

Click **Check Toolchain** to see what's installed. If something is missing, the page that opens shows the exact
install commands for your operating system.
