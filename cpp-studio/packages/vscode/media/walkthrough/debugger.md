# Debugging in the editor

In the debugger lesson your program will crash — on purpose — and you'll find out why by pausing it, line by line,
and looking at every variable.

VS Code needs a C++ debugger extension for that:

- **C/C++** (Microsoft) — works with gdb (Linux), lldb (macOS) and the Visual Studio debugger (Windows).
- **CodeLLDB** — an excellent alternative, especially on macOS.

You only need one.
