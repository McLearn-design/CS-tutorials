# Values, types and a first calculator

Welcome to the C++ Foundations track. From here on you will grow **one project** — a calculator — through several
lessons. It will gain functions, headers, unit tests and error handling, and by the end of the track it will be a
small but properly engineered program.

The project is already set up with the CMake you wrote in Track 0 (`projects/calculator/CMakeLists.txt`). Have a look.

The scaffolding is lighter now: each step explains what you need, and you write the code.
