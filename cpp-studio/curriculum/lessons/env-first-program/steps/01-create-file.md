## Step 1 — Create a source file

A C++ program starts life as plain text in a file. By convention C++ source files end in `.cpp`
(you will also see `.cc` and `.cxx`). There is nothing magic about the file: any editor can write it.

**Your task:** create an empty file named `hello.cpp` in the project folder `projects/hello/`.

Then press **Check**.

> Every lesson works on *real* files in your workspace. Lessons that share a project build on each other —
> the code you write here will be reused when you learn CMake.
