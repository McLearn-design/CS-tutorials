## Step 6 — Challenge: two lines

No code this time — just the requirement.

Make the program print exactly:

```text
Hello C++
I compiled this myself
```

…and build **without any warnings** (C++ Studio compiles with `-Wall -Wextra`, which turns on most useful warnings).

When it passes, you have finished the lesson. Your `hello` project stays in your workspace:
in the CMake lesson you will turn it into a properly built project.
