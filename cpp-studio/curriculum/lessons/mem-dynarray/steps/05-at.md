## Step 5 — Challenge: bounds checking

`a[100]` on a 3-element `IntArray` reads someone else's memory. That's undefined behaviour, and in a non-sanitized
build nothing stops it. `std::vector` offers a checked alternative, `at()`. Add the same to `IntArray`:

- `int& at(std::size_t index)` and `const int& at(std::size_t index) const` — like `operator[]`, but throw
  `std::out_of_range` if `index >= size()`.
- `void pop_back()` — removes the last element; throws `std::out_of_range` if the array is empty.

Write **your own tests** in a new file, `tests/at_test.cpp` (at least three). C++ Studio builds them into a separate test
program, together with `tests/test_main.cpp` and your `int_array.cpp`. Hidden acceptance tests check the edge cases
too.

When this passes, you've built — and understood — the core of the most important container in C++.
