# Independent work: GCD and LCM

Until now, each step has told you what code to write. This lesson doesn't.

You get **requirements and tests**. You decide how to implement them. That's the shift from following a tutorial to
writing software: the tests define *what* must be true; the *how* is yours.

Both functions go into your calculator's `calc.h` / `calc.cpp`. (If you skipped ahead, the project has been
set up with the previous lesson's code.)
